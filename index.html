commands in git

1] git clone - to clone any repo from github to local

2] git add - to add files to the staging area

3] git commit - to commit changes to the local repository

4] git push - to push changes to the remote repository

5] git pull - to pull changes from the remote repository

6] git status - to check the status of the repository

imp note - it all works inside the file which is named in the repo not in the folder you made locally so beaware

what is a branch?

A branch in Git is a separate line of development. It allows you to work on different features or experiments without affecting the main codebase.
